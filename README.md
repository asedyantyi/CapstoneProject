This project uses machine learning to predict the results of Spanish La Liga football matches. By analyzing five seasons of historical data, it compares four different algorithms—Random Forest, SVM, AdaBoost, and KNN—to forecast whether a match will end in a home win, draw, or away win. Random Forest achieved the best performance with 90.61% accuracy. The model has been deployed as an interactive web application using Streamlit, allowing users to select teams and get instant predictions backed by data visualizations. Key insights reveal that goal-related statistics and home advantage are the most significant factors in determining match outcomes
